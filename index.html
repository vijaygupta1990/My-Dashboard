Cloud Sync (makes Save & Share work for everyone)

GitHub Pages can't run a server, so Save/Share need a small free cloud database. Create a free project at console.firebase.google.com → Build → Firestore Database (start in production mode) + Build → Authentication (enable Email/Password) → Project settings → paste your Web app config below.

"Connect Cloud Sync" only saves this config to this browser's storage — other people who open your GitHub Pages link won't have it, so Save/Share will look broken for them. Use "Copy embeddable config", paste it over the EMBEDDED_FIREBASE_CONFIG line near the top of index.html's script, then commit + push to GitHub so it works for everyone automatically.

Recommended Firestore Security Rules (paste in Firebase Console → Firestore → Rules — this is what makes Admin Protection real, not just cosmetic) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /dashboards/{id} { allow read: if true; allow write: if request.auth != null; }
    match /app_settings/{id} { allow read: if true; allow write: if request.auth != null; }
  }
}
